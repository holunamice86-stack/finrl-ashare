# 🧪 多种子复现报告（2026-11-03）

## 实验设计

- **目的**：检验单种子 +45.86% 是「实力」还是「运气」——用 3 个不同随机种子（seed 1/2/3）重复同一实验（30 轮 × 2 万步、lr=1e-5、同一股票池、同一 19 特征、同一选模+留出评估协议）；
- **基准**：同期等权买入持有 +16.58%。

## 结果

| 种子 | 留出段收益（20路径） | vs 持有 |
|---|---|---|
| seed 0（生产模型） | +45.86% | +29.3p |
| seed 1 | **+34.22%** | +17.6p |
| seed 2 | **+27.05%** | +10.5p |
| seed 3 | **+16.39%** | −0.2p |
| **3 新种子平均** | **+25.89%（标准差 ±9.0p）** | **+9.3p** |
| 4 种子总平均 | +30.88% | +14.3p |

## 结论

1. **方向性结论稳健**：3/3 个新种子全部正收益，平均 +25.9% 跑赢持有约 9 个百分点——「19 个市场特征有效」不是单次运气；
2. **幅度要打折**：单种子 +45.9% 处于运气上沿，模型真实水平更接近 **+20%~+35% 区间**（种子间标准差 ±9p）；
3. **种子方差本身就是发现**：同一个算法、同一份数据，只换随机种子，结果从 +16.4% 摆到 +45.9%——**以后引用任何单次回测数字都要记住这个区间**；
4. seed 3 基本与持有打平（−0.2p），提示在保守场景下模型优势可能消失——真实的期望优势在「持有收益 +5~15p」之间。
