# 📖 模型输出说明书（人话版）

> 写给非科班同学：每个数字是什么、从哪来、怎么看。

## 一、模型到底「输出」了什么？

模型不是预测股价，而是**输出一组「动作」**：对池子里的每一只股票给一个数（50 只股票 = 50 个数），
- **正数 = 想买**（数值越大越想买）；
- **负数 = 想卖**（绝对值越大越想卖）；
- **接近 0 = 不想动**。

这些数是「加仓/减仓的股数」的连续值。系统再把它们翻译成可执行的 100 股整数手、并套上 A 股规则。

## 二、网页 ⑤ 区每个数字的含义

### 期望收益排行
| 字段 | 含义 | 例子 |
|---|---|---|
| 评分 | 模型的**均值动作 μ**：它对这只票「想买程度」的稳定偏好（无单位，越大越看好） | +0.65 = 强烈想买 |
| 今日 | 今天单日涨跌幅 | −5.5% = 今天跌了 |
| 20日 | 近 20 个交易日累计涨跌幅（动量） | +7.3% = 20天涨了7.3% |
| 新闻 | DeepSeek 给当天新闻的打分（1负面~5正面；0=没新闻）+ 风险分（1低~5高） | 4分/险3 = 利好、中等风险 |
| ¥现价 | 当前股价 | ¥7.0 |

**怎么看**：评分高 + 今日/20日也强 = 「共识强」；评分高但股价在跌（如之前的寒武纪）= 模型在「抄底」；评分和新闻分都高 = 逻辑最顺。

### 持仓监控表
| 列 | 含义 |
|---|---|
| 持仓 | 模拟盘持有股数 |
| 可卖 | 今天实际能卖的股数（T+1 规则：今天买的明天才能卖） |
| 成本 | 摊薄后的买入成本价 |
| 盈亏% | （现价 − 成本）÷ 成本 |
| 模型信号 | 按均值动作 μ 分档：≥+0.3 强烈买入 / ≥+0.05 买入 / 中间 持有 / ≤−0.05 卖出 / ≤−0.3 强烈卖出 |
| 建议卖出 | 模型想卖多少（= 采样动作 × 可卖份额的上限） |

**怎么看**：信号变「卖出/强烈卖出」且「建议卖出」> 0 = 该考虑卖；信号「买入/强烈买入」且可卖 > 0 = 拿住别慌。

### 买卖建议（按你的资金）
- 在「我可投入资金」框里填你的真实预算（如 10000），建议会：按预算缩股数、只推买得起一手的票、按「单票 ≤ 20%」封顶；
- 不填 = 按模拟盘现金口径（模拟盘满仓时买入列表常为空，正常）。

## 三、训练日志里的数字（第 ① 区）
| 字段 | 含义 |
|---|---|
| EpRet (AverageEpRet) | 每个训练轮（epoch）里，模型平均每局赚/亏多少（原始金额单位）。负 = 还在亏，正 = 开始赚钱，持续爬升 = 在学习 |
| nu / lam | CVaR 风险约束的两个动态参数：nu = 风险阈值（亏损警戒线），lam = 风险惩罚力度。模型一边赚钱一边调整它们，越高 = 风控越紧 |
| bad_trajectory_num | 触发风险惩罚的「坏轨迹」计数 |

## 四、回测指标（第 ② 区）
| 指标 | 含义 | 好坏参考 |
|---|---|---|
| 总收益率 | 期末资产 ÷ 期初 − 1 | 留出段冠军 +21.9% |
| 夏普比率 | 每承担 1 单位风险赚多少（收益÷波动） | >1 算好（冠军 1.25） |
| 最大回撤 | 从最高点到最低点的最大跌幅 | 越小越稳（冠军 −9%） |
| 交易次数/成本 | 换手多=手续费高 | 宽基模型 17% 成本就是被它拖垮的 |

## 五、三个重要认知（别被数字骗了）

1. **模型输出的是「偏好」，不是「预测」**：评分 +0.65 不代表会涨 65%，只代表模型此刻最想买它；
2. **每次点「刷新建议」数字会略有变化**：因为买卖股数来自「随机采样」——这是强化学习探索机制，不是出错；评分（μ）是稳定的，股数会抖；
3. **样本外表现才是真本事**：训练时赚 100% 不重要（可能过拟合），留出段（模型从没见过的日期）的收益才有参考价值。
